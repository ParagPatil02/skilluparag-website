# 💜 SkillUpParag – Career Services Platform

**Your Career. Your Growth. Your Opportunities.**

🌐 Live Website: https://rad-naiad-40e8b9.netlify.app/

SkillUpParag is a responsive career services platform designed to help students, freshers, and job seekers improve their professional profiles and prepare for career opportunities.

## 🚀 Features

- Professional Resume Creation
- LinkedIn Profile Optimization
- Personal Portfolio Website Development
- 1:1 Career Guidance
- Cover Letter Creation
- Internship and Course Documentation
- Service Enquiry Form
- PhonePe QR Payment Integration
- WhatsApp Community Integration
- Social Media and Portfolio Links
- Responsive Design for Mobile and Desktop

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Netlify Forms
- Netlify Hosting
